# 东南大学「IFLand」校内实名社交平台 PRD

## 一、产品定位

**一句话：** 东南大学官方背书的第三方校内交友 App — 攻略市场 + 滑动匹配 + 问答破冰，构建安全可信的深度社交体验。

**核心差异化：**
- 不只是"刷脸匹配"——用**问答破冰机制**替代无脑搭讪
- 不只是"聊天软件"——用**攻略市场经济**激励优质内容
- 不只是"匿名社交"——用**信用评分交叉验证**确保安全

## 三、Tab 1 — 攻略市场（路线攻略 Marketplace）

### 定位
一个 UGC 攻略交易市场。同学发布「去哪玩/怎么玩」的攻略，其他人用平台积分购买解锁。

### 核心流程
```
创作者发布攻略 → 定价（免费/积分）→ 上架市场
                                    ↓
浏览者搜索/浏览 → 购买解锁 → 收藏+使用 → 完成后评分
```

### 攻略内容结构
| 字段 | 说明 |
|------|------|
| 标题 | "九龙湖情侣限定一日游" |
| 路线图 | 多打卡点串联（地图展示） |
| 详细说明 | 每个点做什么、推荐理由 |
| 预算参考 | 人均花费 |
| 适合人数 | 1人/2人/小团体 |
| 标签 | #散步 #美食 #图书馆 |
| 照片 | 最多9张（不露脸） |
| 定价 | 0-50 积分 |

### 攻略类型
| 类型 | 示例 |
|------|------|
| 校园约会路线 | 四牌楼梧桐道→大礼堂→前工院咖啡 |
| 跨校区探索 | 九龙湖骑行至四牌楼全攻略 |
| 美食探店 | 橘园食堂隐藏菜单指南 |
| 自习搭子路线 | 图书馆→教室→通宵自习室 |
| 周边出行 | 紫金山夜爬/玄武湖环湖 |

### 市场机制
```
积分获取：
  ├── 每日签到 +5
  ├── 发布攻略被购买 +1~5（根据定价）
  ├── 信用评价良好 +10/月
  └── 完成打卡任务 +3/次

积分消耗：
  └── 购买攻略（0-50 积分/份）
```

### 交易规则
- 购买后 24 小时内可退款（未使用）
- 攻略售出 100 次以上 → 作者获得"金牌导游"徽章
- 低质量攻略（差评 > 3）→ 自动下架
- 禁止搬运外部内容 → 查重机制

## 四、Tab 2 — 发现（滑动匹配 Discover）

### 定位
Tinder 式卡片滑动。每次展示一位可能感兴趣的人，左滑跳过、右滑感兴趣，双向匹配后进入**问答破冰**阶段。

### 卡片展示内容
```
┌──────────────────┐
│  [头像/照片]      │
│  昵称 + 年级      │
│  学院/专业        │
│  个性签名(一句话)  │
│  共同标签 ×3      │
│  亲密度排名       │
│  [更多资料 ↕]    │
└──────────────────┘
```

### 匹配推荐规则（无 AI，纯规则引擎）
| 权重因子 | 说明 |
|----------|------|
| 共同标签 | +权重，标签重合越多越靠前 |
| 同学院 | ±0（不过度推荐同院，鼓励跨专业） |
| 不同校区 | +权重（鼓励跨校区社交） |
| 信用分 | ≥70 才进入推荐池 |
| 活跃度 | 7 天未登录降低推荐权重 |
| 已匹配/已跳过 | 30 天内不重复出现 |

### 交互
```
左滑 ← 不感兴趣（记录，30天内不重复）
右滑 → 感兴趣（对方也右滑 → 互相匹配成功）
上滑 ↑ 超级感兴趣（消耗积分，强提醒对方）
点击卡片 → 展开完整资料页
```

## 五、Tab 3 — 消息（问答破冰聊天）

### 定位
**不是匹配就能聊——必须先通过问答破冰。** 这是产品的核心创新。

### 聊天准入机制
```
互相匹配 → 进入"问答破冰" → 双方评分 → 解锁聊天
```

### 问答破冰流程
```
Step 1：匹配成功
  └→ 系统随机抽取 3 道破冰问题

Step 2：双方各自回答（48小时内有效，超时匹配失效）
  └→ 双方看不到对方的答案

Step 3：双方都提交后 → 答案互相可见
  └→ 同时展示双方的答案对比

Step 4：看完对方答案 → 双方给对方打分（⭐1-5）
  └→ 盲评：评分时看不到对方给自己打了多少

Step 5：解锁判定
  ├── 双方都 ≥3 星 → 解锁聊天 ✓
  ├── 一方 <3 星 → 匹配解除 ✗
  └── 双方都 ≥4 星 → "灵魂共鸣"标签 + 聊天置顶
```

### 破冰问题池（分类随机抽取）
| 类别 | 示例问题 |
|------|----------|
| 价值观 | "你认为大学里最重要的是什么？" |
| 生活方式 | "周末通常会怎么度过？" |
| 兴趣爱好 | "最近在循环播放的一首歌是？" |
| 趣味脑洞 | "如果明天是世界末日，今天你会做什么？" |
| 东大专享 | "你在东大最喜欢的一个角落是哪里？" |
| 社交期待 | "你下载这个 App 最想找到什么？" |

### 聊天分级
```
阶段 1 — 破冰聊天（刚解锁，72小时）
  ├── 仅文字消息
  └── 系统提示：建议从问答内容开始聊

阶段 2 — 正式聊天（72小时后自动升级）
  ├── 可发送图片
  ├── 可发送校园打卡点位置
  └── 可发起语音通话（需双方同意）

阶段 3 — 亲密聊天（累计互动 > 50 条消息 + 互评良好）
  ├── 开放全部功能
  └── 可申请"见面打卡"任务
```

### 评价升级机制
```
累计互评：
  ├── 3 次双方 ≥4 星 → 解锁"密友"身份标识
  ├── 5 次双方 ≥4 星 → 亲密度榜单加分 ×2
  └── 任意一方连续 2 次 <3 星 → 关系标记"建议冷静"
```

## 七、信用分体系 + 防恶意评分

### 信用分构成（满分100）
| 维度 | 分值 | 说明 |
|------|------|------|
| 实名认证 | +20 | 完成全部认证 |
| 履约记录 | +25 | 攻略评价、问答参与 |
| 行为规范 | ±35 | 举报核实扣分 |
| 社区贡献 | +20 | 发布优质攻略、参与管理 |

### 交叉验证防恶意评分（核心机制）
```
单次评价需三方信号交叉验证才生效：

信号 1 — 双向盲评一致性
  A 给 B 打 4 星 → B 给 A 打 4 星 → 一致 ✓
  A 给 B 打 1 星 → B 给 A 打 4 星 → 矛盾 ⚠ → 降权

信号 2 — 行为事实支撑
  聊天记录：是否有实质性对话
  攻略购买/使用：是否确实交易过
  
信号 3 — 历史画像
  用户 A 历史打分平均 1.2 星 → 可能是恶意评分者 → 该用户评分降权
  用户 B 历史被评分平均 4.5 星 → 可信度高

三方信号加权判定 → 最终信用分变动
恶意评分识别 → 标记 → 人工审核 → 降权/封禁
```

## 八、亲密度与排行榜

### 关系层级
```
陌生人 → 匹配 → 破冰 → 好友 → 密友 → CP
```

### 亲密度计算公式
```
亲密度 = 
  互发消息 × 1 +
  连续互动天数 × 3 +
  互评 ⭐4以上 × 5 +
  互相购买攻略 × 10 +
  共同打卡 × 15
```

### 排行榜（赛季制）
| 榜单 | 说明 |
|------|------|
| CP 甜蜜榜 | 双人亲密度排行 |
| 搭子默契榜 | 组队完成任务的搭子 |
| 攻略达人榜 | 发布攻略被购买次数 |
| 破冰高手榜 | 问答评分最高的用户 |

每月重置，历史数据存档，TOP3 获得第二课堂学分。

## 十二、数据库核心表设计（概要）

```
users          — 用户（学号、姓名、身份证后6位、昵称、学院、年级、信用分）
profiles       — 资料卡（照片、签名、标签）
guides         — 攻略（标题、内容、路线、定价、销量）
orders         — 购买记录
matches        — 匹配记录（双方ID、状态、时间）
questions      — 破冰问题池
answers        — 问答记录（问题、双方答案、评分）
messages       — 聊天消息
ratings        — 用户互评（评分、三方验证信号）
checkins       — 打卡记录（GPS、时间、照片）
intimacy       — 亲密度快照
leaderboards   — 排行榜快照
```

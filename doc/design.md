# IFLand App 设计文档（Design）

---

## 1. App 整体结构

### 1.1 底部导航（3 Tab）

```
┌──────────────────────────────────────────┐
│  🏠 广场      │  💘 发现      │  💬 消息 │
│  (Plaza)      │  (Discover)   │  (Chat)  │
└──────────────────────────────────────────┘
```

| Tab | 路由 | 名称 | 功能定位 |
|-----|------|------|----------|
| 1 | `/plaza` | 广场 | 活动广场 + 攻略市场 + 好友动态，多分区内容聚合 |
| 2 | `/discover` | 发现 | 卡片滑动浏览用户，下滑查看详情，加号发起破冰问答 |
| 3 | `/chats` | 消息 | 会话列表 + QQ 式聊天 |

### 1.2 全局交互约定

- **桌面端**：375×812 手机框居中，渐变背景装饰
- **移动端**：全屏自适应（`window.innerWidth ≤ 768` 触发）
- **顶部栏**：各 Tab 页有独立 Header，子页面有返回箭头
- **Token 过期**：任意 API 返回 10002 → 自动跳转 `/login`
- **加载态**：骨架屏（Skeleton），不用全屏 Loading
- **空状态**：统一 EmptyState 组件，含插画 + 引导文案 + 行动按钮

## 3. Tab2 — 发现（Discover）

### 3.1 页面定位

> 浏览潜在好友的核心页面。两层交互：左右滑动浏览卡片，下滑展开全屏资料。底部中心「＋」按钮发起好友申请（进入破冰问答）。

```
│            │              │              │     背后2张
│            │              │              │     缩至 95%/90%
│            │              │              │
│            │  思思        │              │
│            │  建筑学院 大三│              │
│            │              │              │
│            │  [咖啡][摄影] │              │  ← 共同标签高亮
│            │  [CityWalk]  │              │
│            └──────────────┘              │
│                                          │
│               ┌──────┐                   │
│               │  ＋   │                   │  ← 底部中心按钮
│               └──────┘                   │     表示感兴趣
│                                          │
│  ✕ 不感兴趣               💬 查看详情    │  ← 底部操作栏
│    (左滑)                  (下滑/点击)    │
└──────────────────────────────────────────┘
```

**交互说明：**
| 手势 | 触发 | 视觉反馈 |
|------|------|----------|
| 左滑（x < -80px） | 不感兴趣，卡片飞出，下一张 | 红色遮罩渐显，卡片左飞 |
| 右滑（x > 80px） | 标记喜欢，卡片飞出，下一张 | 绿色遮罩渐显，卡片右飞 |
| 下滑（y > 100px） | **卡片放大到全屏**，进入详情模式 | 卡片从当前位置展开到全屏 |
| 点击卡片 | 同下滑，进入全屏详情 | 同下滑 |
| 点击「＋」按钮 | 发起好友请求 → 进入破冰问答 | 按钮呼吸动画 → 跳转 |

> **注意：** 右滑"喜欢"不会直接触发匹配。它是一种轻量标记（提高推荐权重），真正的"想交朋友"通过点击「＋」发起破冰问答。

## 4. 破冰问答（核心交友机制）

### 4.1 流程总览

```
A 在发现页看到 B 的卡片
  ↓
A 下滑查看 B 的完整资料
  ↓
A 觉得有趣 → 点击「＋认识Ta」
  ↓
A 回答 B 预设的 + 系统随机的问题
  ↓
B 收到通知 "有人想认识你，并回答了你的问题"
  ↓
B 查看 A 的答案
  ↓
B 觉得回答有意思 → ✅ 确认通过
B 觉得不合适      → ❌ 婉拒
  ↓ (通过)
聊天解锁，A 和 B 可以开始聊天
```

### 4.2 问题来源

```
每个用户可以在个人资料中预设 1-3 道「破冰问题」
  + 系统从题库随机抽取 2 道
  = 总共 3-5 道问题
```

**示例：**

| 来源 | 问题 |
|------|------|
| B 预设 | "如果一起去旅行，你最想去哪里？" |
| B 预设 | "周末一般怎么度过？" |
| 系统 | "你认为大学里最重要的事是什么？" |
| 系统 | "最近在循环播放的一首歌？" |

## 8. 页面状态与过渡动画

### 8.1 发现页卡片 → 全屏过渡

```
卡片模式 (scale:1, y:0, borderRadius:16)
     │
     │ 下滑手势 / 点击
     ↓
全屏模式 (scale:1, y:-topOffset, borderRadius:0)
     │
     │ 上滑手势 / 点击返回
     ↓
卡片模式

动画: spring, duration 0.3s, 使用 framer-motion AnimatePresence
```

### 8.2 页面转场

```
push: 从右滑入 (slide left)
pop:  向右滑出 (slide right)
modal: 从下弹入 (slide up)

使用 framer-motion <AnimatePresence mode="wait">
```

### 8.3 加载与空状态

| 场景 | 展示 |
|------|------|
| 首次加载 | Skeleton 骨架屏（灰色闪烁块） |
| 加载更多 | 底部小菊花 spinner |
| 列表为空 | EmptyState 插画 + 引导文案 |
| 网络错误 | ErrorState + 重试按钮 |
| 下拉刷新 | Pull-to-refresh (移动端原生手感) |

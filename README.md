# 东大同行

东大同行是一个面向东南大学学生的校内可信社交与共同行动平台，帮助同学通过学习搭子、校园路线、兴趣匹配和电子徽章，在安全、低压力的环境中认识彼此、探索校园、共同成长。

## 项目定位

这不是普通交友软件，而是适合校方、学生会、社团和同学接受的校园可信社交与共同行动 MVP。平台突出校内可信身份、隐私保护、低压力社交、公共空间见面、校园路线打卡、电子徽章和同行值。

## 核心功能

- Mock 校内统一身份认证登录
- 用户公开资料与隐私可见性设置
- 兴趣交友推荐与可解释匹配理由
- 搭子广场、搭子发布、申请加入、接受/拒绝/关闭 mock 流程
- 认真关系意向频道，每日最多 3 个推荐，必须双向选择后聊天
- 校园路线列表、详情和手动/mock QR 打卡
- 电子徽章墙与同行值
- 双向匹配后的安全聊天
- 信用状态与举报
- 管理端 Dashboard、举报处理、路线审核、用户风控

## 为什么不是普通交友软件

- 不展示真实姓名、学号、手机号、身份证号或宿舍楼栋
- 不做实时定位，不鼓励私密场所见面
- 不做颜值打分、亲密度榜单或附近的人
- 认真关系频道不进入公开榜单，不换算成官方奖励
- 信用分只用于治理和风控，不公开排名

## 隐私与安全设计

普通用户默认只看到昵称、校区、学院大类、年级区间和兴趣标签，且这些字段可隐藏。首次线下见面推荐校园公共空间；聊天支持举报、拉黑和取消匹配；管理员操作返回 mock 审计轨迹。

## 技术栈

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- lucide-react
- 本地 mock 数据与 mock API

## 本地运行

```bash
npm install
npm run dev
```

然后打开 `http://localhost:3000`。

## 环境变量

MVP 不需要环境变量。后续接入真实认证、数据库或对象存储时可增加 `.env.local`。

## 页面说明

主要页面包括 `/`、`/login`、`/profile`、`/discover`、`/partners`、`/partners/new`、`/relationship`、`/routes`、`/routes/[id]`、`/badges`、`/chat`、`/chat/[id]`、`/reputation`、`/admin`、`/admin/reports`、`/admin/routes`、`/admin/users`。

## API 说明

已提供计划中的 mock API，包括认证、用户资料、好友推荐、搭子需求、关系意向、路线、徽章、同行值、聊天、举报、信用状态和管理端操作。所有 POST 类治理操作都会返回 `auditTrailId`。

## Mock 数据

mock 数据位于 `src/data/mock`，包含 12 个用户、8 条搭子需求、3 条官方路线、2 条待审路线、7 个徽章、聊天房间、信用资料和 3 条举报。

## Demo 流程

详见 [DEMO.md](./DEMO.md)。

## 后续接入统一身份认证

保留 `/api/auth/mock-login` 作为适配点。真实接入时建议只保存校内认证后的不可逆用户标识、校区、学院大类和年级区间，不保存身份证号，不在普通页面展示真实姓名和学号。

## 后续接入学生会/社团管理

可在管理端增加组织角色、路线共建、活动审核和社团白名单。社团可提交路线和搭子活动，平台继续保留公共空间、安全提醒和管理员留痕。
